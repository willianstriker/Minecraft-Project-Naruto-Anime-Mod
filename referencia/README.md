# Mods de referência

Estes são os **jars originais** que serviram de base para o port — guardados aqui para consulta futura.

| Arquivo | O que é |
|---|---|
| `Naruto-Anime-Mod_V0.9.17_Beta_1.7.10-1.0.jar` | O mod original (Mathioks, MC 1.7.10) — fonte do conteúdo portado |
| `NarutoMod-1.20-1.8.1-universal.jar` | Sekwah41's Naruto Mod (MC 1.20) — referência do sistema de teclas C/V/B |
| `SekCLib-1.20-1.0.2-universal.jar` | Biblioteca de rede do Sekwah41's |

> Estes arquivos **não** são usados em tempo de execução pelo mod portado.
> Servem para: consulta de comportamento original, extração de assets (texturas, sons, modelos),
> e decompilação quando for necessário portar novos sistemas.
