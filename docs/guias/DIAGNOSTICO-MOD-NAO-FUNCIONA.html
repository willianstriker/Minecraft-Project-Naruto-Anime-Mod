Solução de problemas

O mod não funcionou? Vamos descobrir o porquê

Faça os 4 testes abaixo na ordem. O primeiro que falhar é a causa do problema.
⚠️ O erro nº 1 que as pessoas cometem
❌ ERRADO: colocar o arquivo em versions/mods
    (essa pasta não existe / não serve para mods)

✅ CERTO: colocar o arquivo em .minecraft/mods

Como saber se você está na pasta certa:
A pasta mods fica no mesmo lugar onde estão as pastas saves, logs, config e o arquivo options.txt.
📁 .minecraft/
  ├── 📁 mods       ← O JAR VAI AQUI
  │    └── 📄 narutoanimemod-26.3-v0.1.0.jar
  ├── 📁 saves
  ├── 📁 logs
  ├── 📁 config
  └── 📄 options.txt
💡 No TLauncher, use o botão "Open folder" / "Abrir pasta" para abrir o lugar certo automaticamente. Não adivinhe o caminho!
1
O jogo está rodando com FORGE?
Abra o Minecraft e olhe o canto inferior esquerdo da tela do menu principal:
Singleplayer  Multiplayer
Options...  Quit Game
Minecraft 26.3 / Forge 66.0.12
✅ CERTO — aparece "Forge"
Singleplayer  Multiplayer
Options...  Quit Game
Minecraft 26.3
❌ ERRADO — sem Forge, nada de mod vai funcionar
Se não aparecer "Forge": você está abrindo o Minecraft normal. Precisa instalar o Forge (veja o passo extra no final desta página).
2
O jogo vê o mod?
No menu principal, clique no botão "Mods" (perto de Options/Opções).
Procure na lista: deve ter Naruto Anime Mod.
Mods (2)
🔧 Forge  66.0.12
🍥 Naruto Anime Mod  1.0.0  — Mathioks, ninjaespio1000, Sekwah41's, willianstriker
Se o mod não está na lista: o arquivo está na pasta errada, é a versão errada do Minecraft, ou o Forge não está ativo.
3
O teste definitivo: o arquivo de log
Este teste nunca falha: ele mostra se o mod carregou, mesmo que algo dê errado depois.

Como fazer:
1. Abra a pasta .minecraft/logs
2. Abra o arquivo latest.log com o Bloco de Notas
3. Aperte Ctrl + F e procure por: jutsus ativos
✅ ACHOU?
[Naruto Anime Mod] canal de rede iniciado (v1)
[Naruto Anime Mod] 33 jutsus ativos no sistema de combos C/V/B
→ O mod está carregando. O problema é dentro do jogo (veja o Teste 4).
❌ NÃO ACHOU?
O mod não está sendo carregado. Causas possíveis:
• arquivo na pasta errada
• jogando sem Forge
• arquivo virou .zip em vez de .jar
• versão diferente do Minecraft (este mod é só para 26.3)
4
O mod carregou, mas as teclas não fazem nada?
Aí é bem mais simples — provavelmente as teclas foram para outro lugar ou são outra tecla:
1. Opções → Controles → Teclas
2. Role até a categoria Naruto Anime Mod
3. Confira as teclas: C, V e B
4. Se estiverem vazias, clique e defina você mesmo
5. Clique em Concluído e teste no mundo
Teste básico: aperte C e espere meio segundo → deve aparecer uma mensagem no chat. Se não aparecer nada, veja se você está dentro do mundo (não no menu) e se o jogo não está pausado.
🔧 Os 6 erros mais comuns (confira todos)
❌ Erro ✅ Correção
Colocou em versions/mods Use .minecraft/mods
Colocou o arquivo .zip na pasta mods O Minecraft só lê .jar — extraia o zip
Abrindo a versão "Release 26.3" (sem Forge) Abra a versão forge-26.3-66.0.12
Jogo rodando com Java 17 ou 21 O 26.3 exige Java 25 — mude no launcher
Tentando em outra versão (1.20, 1.7.10...) Este mod é exclusivo para 26.3
Colocou em outro .minecraft (o launcher usa outro) Use "Open folder" do TLauncher
🛠️ Extra: como instalar o Forge 26.3 (se o Teste 1 falhou)
1. Baixe o instalador do Forge 26.3:
https://maven.minecraftforge.net/net/minecraftforge/forge/26.3-66.0.12/forge-26.3-66.0.12-installer.jar
2. Dê 2 cliques no arquivo baixado (se abrir perguntando como abrir, escolha Java)
3. Marque "Install client" e aponte a pasta para o seu .minecraft (use o "Open folder" do TLauncher para descobrir qual é)
4. Clique em OK e espere terminar
5. Reinicie o TLauncher → na lista de versões vai aparecer forge-26.3-66.0.12
6. Selecione essa versão e abra o jogo uma vez (isso cria a pasta mods) → feche
7. Coloque o .jar em .minecraft/mods → abra o jogo de novo pela versão Forge
💡 Se o instalador não abrir: falta o Java 25 no PC. Baixe em adoptium.net (escolha "Temurin 25" para Windows) e instale.

4. Print do TLauncher mostrando qual versão está selecionada
Com essas 4 informações eu descubro a causa exata em segundos. 🙂
