Como colocar o mod no seu GitHub

✅ Sem instalar nada  ·  ✅ Sem usar terminal/comando  ·  ✅ Só o navegador
Tempo: cerca de 10 minutos. Vá com calma, um passo por vez.
📦 Antes de começar — os arquivos
Baixe o arquivo NarutoAnimeMod-26.3-PARA-O-GITHUB.zip (está na mesma pasta deste guia).
Ele contém 66 arquivos — o código do mod, a documentação e o mod pronto para jogar.
1
Criar sua conta no GitHub (se ainda não tem)
Abra o navegador e vá em github.com
• Se já tem conta: clique em Sign in e faça login
• Se não tem: clique em Sign up, coloque seu e-mail, uma senha e escolha um nome de usuário
Anote seu nome de usuário — você vai precisar dele no passo 3.
2
Extrair o zip que você baixou
Vá na pasta Downloads do seu computador.
• Windows: clique com o botão direito no arquivo NarutoAnimeMod-26.3-PARA-O-GITHUB.zip → Extrair Tudo... → Extrair
• Mac: clique 2 vezes no arquivo (ele extrai sozinho)

Vai aparecer uma pasta chamada NarutoAnimeMod-26.3. Abra ela.
Dentro você verá: README.md, build.gradle, src, docs, tools, jar...
3
Criar o repositório (a "pasta" no GitHub)
No navegador, abra: github.com/new

Você vai ver um formulário parecido com este:
Repository name
NarutoAnimeMod-26.3 ✔ disponível
⚠️ MUITO IMPORTANTE: NÃO marque nenhuma dessas caixinhas:
☐ Add a README file    ☐ Add .gitignore    ☐ Choose a license
(se marcar, o GitHub cria arquivos que vão dar conflito no passo 5)
Create repository
Digite o nome NarutoAnimeMod-26.3, deixe em Public e clique no botão verde Create repository.
4
Enviar os arquivos (a parte mágica)
Depois de criar, o GitHub mostra uma página dizendo "Quick setup" com alguns comandos. Ignore esses comandos. Em vez disso, procure o link azul escrito:
uploading an existing file
← clique nesse link
Isso abre uma página que diz "Drag files here to add them to your repository".

Agora faça isso:
1. Volte para a pasta NarutoAnimeMod-26.3 que você extraiu
2. Aperte Ctrl + A (Mac: Cmd + A) para selecionar TODOS os arquivos de dentro dela
3. Arraste tudo para dentro do navegador, na área que diz "Drag files here"
4. Espere a lista de arquivos aparecer (pode levar uns segundos)
⚠️ Dica: selecione o que está dentro da pasta (README.md, build.gradle, src, docs...), e não a pasta inteira.
5
Confirmar o envio
Role a página até o final. Você vai ver:
Commit changes
Add files via upload
Commit changes
Clique no botão verde Commit changes e espere alguns segundos.
6
Pronto! Confira o resultado
A página vai mostrar seus arquivos, e o seu README aparece bonito embaixo, já formatado. 🎉

O endereço do seu repositório será:
github.com/SEU-USUARIO/NarutoAnimeMod-26.3
🔧 Se algo der errado
Não achei "uploading an existing file"
→ Na página do repositório, clique em Add file (botão ao lado do verde "Code") → Upload files

O botão verde está cinza/apagado
→ Você não selecionou nenhum arquivo. Feche a página e refaça o passo 4.

Apareceu erro de "conflict" / "already exists"
→ Você marcou "Add a README file" ao criar o repositório. Solução: apague o repositório (Settings → role até o fim → Delete this repository) e crie de novo vazio.

A área de arrastar não aceita minhas pastas
→ Use Chrome ou Edge (funcionam melhor). Se não der, envie em partes: primeiro os arquivos soltos (README, build.gradle...), depois as pastas src, docs, tools e jar.
💡 E depois? Como atualizar mais tarde
Quando eu te entregar a próxima versão (mais jutsus, HUD, tela de jutsus), você repete só os passos 4 e 5: abre seu repositório, clica em Add file → Upload files, arrasta os arquivos novos e clica em Commit changes. O GitHub guarda todo o histórico — nada é perdido.

Atalho: se preferir, apague o arquivo antigo pela própria página do GitHub (ícone de lixeira) e suba o novo.
