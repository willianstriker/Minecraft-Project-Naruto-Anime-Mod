Port 26.3 · v0.1.1 · atualizado em 16/10/2026

Não deu certo? Agora tem explicação — e um instalador

Resumo: o tamanho de 50 KB é normal, o jar grande de 20/40 MB não funciona no 26.3 mesmo, e a instalação agora é automática.

1) Por que o mod tem só 50 KB?

Mod original (1.7.10)

20,4 MB (20.396.504 bytes)

ConteúdoTamanho
Texturas, modelos, sons (assets)21,0 MB
Código (alcoholmod etc.)10,7 MB
Resto (Susanoo, pacotes, mcmod.info)~0,2 MB

Nosso port 26.3 (v0.1.0 / v0.1.1)

~50 KB (50.246 bytes)

ConteúdoTamanho
Texturas, modelos, sons0 (ainda não entrou)
12 classes de código (combos, jutsus, rede)~45 KB
34 conquistas + textos PT/EN~10 KB
O tamanho de um mod é quase todo textura/som. Só para comparar: a biblioteca SekCLib do Sekwah41's (que também é só código, sem texturas) tem 48,9 KB — praticamente igual ao nosso. Ou seja: 50 KB é normal e não quer dizer arquivo quebrado. Nos testes aqui no meu ambiente o jar passou: Loaded 1900 advancements e 33 jutsus ativos no sistema de combos C/V/B.

2) E aquele jar de 20/40 MB? Esse nunca vai funcionar no 26.3

O arquivo grande é o mod ANTIGO (1.7.10 ou o de 1.20 do Sekwah41's). O Forge do Minecraft 26.3 nem reconhece o formato antigo — ele não vai carregar de jeito nenhum, em nenhum modpack. É exatamente por isso que eu estou fazendo este port.

Importante: a pasta referencia/ do GitHub tem esses jars antigos (o original de 20,4 MB) só como fonte de consulta do código. Não baixe nada de lá para jogar — o único arquivo para jogar é o narutoanimemod-26.3-*.jar (~50 KB) do Release.

Faça agora: abra a pasta mods e tire qualquer jar grande (20 MB, 40 MB...) que estiver lá. Só pode ficar o narutoanimemod-26.3-*.jar.

Me diz na próxima mensagem de onde veio o jar de 40 MB (qual site/pasta)? Quero confirmar que não é outra coisa.

3) Instalador automático: INSTALAR-MOD.bat

Baixe o ZIP que eu mandei no chat (NarutoAnimeMod-26.3-v0.1.1-COM-INSTALADOR.zip), extraia em qualquer pasta (ex.: Downloads) e siga:

1
Feche o Minecraft.
2
Dê duplo clique em INSTALAR-MOD.bat. Se o Windows avisar (SmartScreen), clique em Mais informações → Executar assim mesmo (é um arquivo de texto simples, código aberto, dá pra abrir no Bloco de Notas e ler tudo).
3
Escolha [3] Instalar nos dois — ele copia o jar para .minecraft\mods e para a pasta do modpack, e ainda gera o relatório.
4
Abra o jogo (versão Forge 26.3 ou o seu modpack) e entre num mundo.
5
Rode o script de novo e escolha [4] Somente gerar o RELATORIO. Aí ele copia o log NOVO do jogo.

O que o script faz: localiza o jar, mostra a pasta de cada versão/modpack do TLauncher, copia o jar para a pasta certa (criando a pasta mods se não existir) e gera uma pasta RELATORIO com o log e possíveis crashs. Nada é apagado.

Boa notícia do seu print: o rodapé do menu mostra Forge Beta 66.0.12 — ou seja, o Forge do 26.3 está rodando aí. O que falta é só o jar certo estar na pasta que o Forge lê. É isso que o script resolve.

4) Como conferir que o mod carregou (3 sinais)

  • Tela "Mods" (no menu principal): "Naruto Anime Mod" na lista — role a lista até achar.
  • Chat ao entrar no mundo (novo na v0.1.1): mensagem [Naruto Anime Mod] 33 jutsus ativos - combos C/V/B. A aba de conquistas (tecla L) mostra as combinações. — se essa mensagem aparecer, o mod carregou 100%.
  • Conquistas (tecla L): deve ter a aba do mod com as combinações de cada jutsu. Em Opções → Controles, procure "Naruto": as teclas C V B (jutsus) e J (tela de jutsus, em construção).

5) Se ainda não aparecer: me mande o relatório

Na pasta do script vai ter a pasta RELATORIO com:

  • RELATORIO.txt — lista TODAS as pastas de versões/modpacks, o que tem em cada mods e a versão do Minecraft de cada uma (linha inheritsFrom);
  • LOG-raiz.txt e LOG-<modpack>.txt — o log do jogo de cada perfil;
  • CRASH-* — se o jogo tiver travado, o relatório do crash aparece aqui.

Me envie o RELATORIO.txt + os LOG-*.txt + um print da tela Mods do jogo. Com isso eu sei exatamente o que está acontecendo: pasta errada, versão errada ou travamento — e corrijo.

6) Modo manual (se preferir sem script)

1
Abra %appdata%\.minecraft (cole isso na barra de endereço do Explorador).
2
Para a versão normal: copie o narutoanimemod-26.3-v0.1.1.jar para .minecraft\mods (crie a pasta se não existir).
3
Para o modpack: copie o mesmo jar para .minecraft\versions\Naruto Anime Mod 0.1.0\mods (crie a pasta mods se não existir).
4
Confirme que o arquivo termina em .jar (clique com o botão direito → Propriedades).
5
Abra o jogo pelo perfil certo e confira os 3 sinais do item 4.
Ver o código completo do INSTALAR-MOD.bat (copiar e colar)

Cole em um Bloco de Notas e salve como INSTALAR-MOD.bat (em "Salvar como", escolha Todos os arquivos), na mesma pasta do jar.

@echo off
setlocal EnableDelayedExpansion
title Naruto Anime Mod 26.3 - Instalador + Relatorio
color 0B

rem ============================================================
rem  INSTALAR-MOD.bat  -  Naruto Anime Mod [port 26.3 / Forge 66]
rem  Codigo aberto MIT. Nada e apagado: o script apenas COPIA o
rem  jar para a pasta certa e gera um RELATORIO para enviar.
rem ============================================================

set "MC=%APPDATA%\.minecraft"
set "HERE=%~dp0"
set "RELDIR=%HERE%RELATORIO"
set "JAR="
set "JARNAME="
set "JARBYTES=0"
set "DEST="

echo ============================================================
echo    NARUTO ANIME MOD 26.3   -   INSTALADOR + RELATORIO
echo ============================================================
echo.
echo  Feche o Minecraft antes de continuar.
echo.

if not exist "%MC%" (
    echo  [ERRO] Nao encontrei a pasta:
    echo         %MC%
    echo.
    echo  Se o seu Minecraft fica em outro lugar, extraia este
    echo  arquivo para dentro da pasta .minecraft e rode de novo.
    echo.
    pause
    exit /b 1
)
echo  Pasta do Minecraft: %MC%
echo.

rem ---------- 1. localizar o jar ----------
for /f "delims=" %%F in ('dir /b /o-n "%HERE%narutoanimemod*.jar" 2^>nul') do set "JAR=%HERE%%%F"
if not defined JAR for /f "delims=" %%F in ('dir /b /o-n "%USERPROFILE%\Downloads\narutoanimemod*.jar" 2^>nul') do set "JAR=%USERPROFILE%\Downloads\%%F"
if not defined JAR (
    echo  [ATENCAO] Nao encontrei nenhum arquivo narutoanimemod*.jar
    echo            nesta pasta nem na pasta Downloads.
    echo.
    echo  Dica: arraste o arquivo .jar para dentro desta janela
    echo        preta e aperte ENTER.
    echo.
    set /p "JAR=Jar: "
    set "JAR=!JAR:"=!"
)
if defined JAR (
    for %%F in ("!JAR!") do ( set "JARNAME=%%~nxF" & set "JARBYTES=%%~zF" )
    set /a JARKB=JARBYTES/1024
    echo  Arquivo: !JARNAME! - !JARKB! KB
    if !JARBYTES! GTR 524288 (
        echo.
        echo  *** AVISO IMPORTANTE ***
        echo  Este arquivo tem !JARKB! KB. O jar certo do port 26.3 tem
        echo  cerca de 50 KB. Arquivos de 20 MB / 40 MB / 100 MB sao os
        echo  mods ANTIGOS de 1.7.10 ou 1.20 e NAO funcionam no 26.3.
        echo  Use SOMENTE o narutoanimemod-26.3-*.jar do GitHub.
        echo.
    )
    echo.
)

:menu
echo ------------------------------------------------------------
echo  Onde instalar?
echo.
echo    [1] Versao normal Forge 26.3  ....  %MC%\mods
echo    [2] Modpack do TLauncher      ....  %MC%\versions\NOME\mods
echo    [3] Instalar nos dois + relatorio
echo    [4] Somente gerar o RELATORIO - nao instala nada
echo    [0] Sair
echo.
set /p "OP=Digite o numero e aperte ENTER: "
echo.

if "!OP!"=="0" goto :fim
if "!OP!"=="1" goto :inst_raiz
if "!OP!"=="2" goto :inst_pack
if "!OP!"=="3" goto :inst_tudo
if "!OP!"=="4" goto :relatorio
echo  Opcao invalida.
goto :menu

:inst_raiz
set "DEST=%MC%"
call :copiar
goto :relatorio

:inst_pack
echo  Pastas em %MC%\versions :
echo.
set /a N=0
for /d %%D in ("%MC%\versions\*") do (
    set /a N+=1
    set "P[!N!]=%%~nxD"
    echo    [!N!] %%~nxD
)
if !N! EQU 0 (
    echo.
    echo  [ERRO] Nenhuma pasta em %MC%\versions
    echo.
    pause
    goto :menu
)
echo.
echo    [0] voltar ao menu
echo    Dica: o seu modpack tem Naruto no nome, escolha ele.
echo.
set /p "PN=Numero da pasta do modpack: "
if "!PN!"=="0" goto :menu
set "NOME=!P[%PN%]!"
if not defined NOME (
    echo  Numero invalido.
    echo.
    goto :inst_pack
)
set "DEST=%MC%\versions\!NOME!"
call :copiar
goto :relatorio

:inst_tudo
set "DEST=%MC%"
call :copiar
for /d %%D in ("%MC%\versions\*") do (
    set "PUT="
    if exist "%%~fD\mods" set "PUT=1"
    echo %%~nxD | findstr /i /c:"naruto" >nul && set "PUT=1"
    if defined PUT (
        set "DEST=%%~fD"
        call :copiar
    )
)
goto :relatorio

:copiar
if not defined JAR (
    echo  [ERRO] Nenhum jar selecionado. Nada foi instalado.
    echo.
    exit /b 1
)
if not exist "!DEST!" (
    echo  [ERRO] A pasta nao existe: !DEST!
    echo.
    exit /b 1
)
if not exist "!DEST!\mods" mkdir "!DEST!\mods"
copy /y "!JAR!" "!DEST!\mods\" >nul
if errorlevel 1 (
    echo  [ERRO] Falha ao copiar para !DEST!\mods
) else (
    echo  [OK] Instalado em: !DEST!\mods\!JARNAME!
)
echo.
exit /b 0

:relatorio
if not exist "%RELDIR%" mkdir "%RELDIR%"
set "REP=%RELDIR%\RELATORIO.txt"
echo RELATORIO - Naruto Anime Mod 26.3 > "%REP%"
echo Data: %DATE% %TIME% >> "%REP%"
echo Pasta .minecraft: %MC% >> "%REP%"
echo Jar usado: !JAR! >> "%REP%"
echo Ultimo destino instalado: !DEST! >> "%REP%"
echo. >> "%REP%"
echo ==== [A] CONTEUDO DE %MC%\mods ==== >> "%REP%"
if exist "%MC%\mods" (dir "%MC%\mods" >> "%REP%") else (echo PASTA NAO EXISTE >> "%REP%")
echo. >> "%REP%"
echo ==== [B] PASTAS DE VERSAO DO LAUNCHER ==== >> "%REP%"
for /d %%D in ("%MC%\versions\*") do (
    echo --- %%~nxD >> "%REP%"
    if exist "%%~fD\%%~nxD.json" findstr /i /c:"inheritsFrom" "%%~fD\%%~nxD.json" >> "%REP%" 2>nul
    if exist "%%~fD\mods" (
        dir /b "%%~fD\mods" >> "%REP%"
    ) else (
        echo     [sem pasta mods] >> "%REP%"
    )
)
echo. >> "%REP%"
echo ==== [C] LOGS E CRASHES ==== >> "%REP%"
if exist "%MC%\logs\latest.log" (
    copy /y "%MC%\logs\latest.log" "%RELDIR%\LOG-raiz.txt" >nul
    echo copiado: LOG-raiz.txt >> "%REP%"
)
for /d %%D in ("%MC%\versions\*") do (
    set "PUT="
    if exist "%%~fD\mods" set "PUT=1"
    echo %%~nxD | findstr /i /c:"naruto" >nul && set "PUT=1"
    if defined PUT (
        if exist "%%~fD\logs\latest.log" (
            copy /y "%%~fD\logs\latest.log" "%RELDIR%\LOG-%%~nxD.txt" >nul
            echo copiado: LOG-%%~nxD.txt >> "%REP%"
        )
        if exist "%%~fD\crash-reports" (
            xcopy /y /i /e "%%~fD\crash-reports" "%RELDIR%\CRASH-%%~nxD\" >nul 2>nul
            echo copiado: CRASH-%%~nxD >> "%REP%"
        )
    )
)
if exist "%MC%\crash-reports" (
    xcopy /y /i /e "%MC%\crash-reports" "%RELDIR%\CRASH-raiz\" >nul 2>nul
    echo copiado: CRASH-raiz >> "%REP%"
)
echo. >> "%REP%"
echo ==== [D] SISTEMA ==== >> "%REP%"
ver >> "%REP%"
echo. >> "%REP%"
echo ==== FIM ==== >> "%REP%"

echo.
echo ============================================================
echo  PRONTO!
echo.
echo  1. O relatorio esta em: %RELDIR%
echo  2. Abra o Minecraft na versao Forge 26.3 ou no modpack
echo  3. Confira a tela Mods: deve aparecer Naruto Anime Mod
echo  4. Depois de jogar, rode este script de novo e escolha [4]
echo     para gerar um relatorio com o log NOVO.
echo.
echo  Envie no chat: o arquivo RELATORIO.txt + os LOG-*.txt
echo  e um print da tela Mods do jogo.
echo ============================================================
start "" "%RELDIR%"
pause
goto :fim

:fim
endlocal
exit /b 0
