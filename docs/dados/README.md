# Dados extraídos do mod original

Arquivos gerados pela análise dos jars do mod 1.7.10, usados como base do port.

| Arquivo | O que é |
|---|---|
| `itens_extraidos_1.7.10.txt` | Lista bruta dos itens (classe interna → nome exibido) extraída do `en_US.lang` |
| `../catalogo_jutsus.csv` | Catálogo completo classificado: 510 itens de ativação (removidos) e 320 de equipamento (mantidos) |
| `../jutsus.json` | Os mesmos dados em JSON, com as combinações de teclas atribuídas |

Gerado por [`tools/gerar_catalogo.py`](../../tools/gerar_catalogo.py).
